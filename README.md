# AutoVerse 🚗

AutoVerse is a frontend automotive blogging and car discovery website made for a Web Application Development academic project.

## Technologies
- HTML5
- CSS3
- JavaScript
- Browser localStorage

## Features
- Car model collection
- Search and category filtering
- Car details and specifications
- Automotive blogs
- Automotive destinations
- Wallpaper download feature
- Wishlist using localStorage
- Registration and login form validation
- Profile page
- Dark/light mode
- Responsive design

## Database
No database is used. User account and wishlist demonstration data are stored in the browser using localStorage.

## How to run
Open `index.html` in a browser, or use VS Code with the Live Server extension.

## GitHub Pages
Upload the project to GitHub and enable Pages from Settings → Pages → Deploy from branch → main → root.

## Important
The project contains placeholder image paths in `images/cars/`. Add your own legally usable car images using these filenames:
aventador.jpg, sf90.jpg, chiron.jpg, porsche911.jpg, gtr.jpg, supra.jpg, mustang.jpg, amggt.jpg, models.jpg

For an academic demonstration, replace placeholders with images you are allowed to use.
